# Gedragscode

## Onze belofte

Wij willen dat deelname aan dit project voor iedereen prettig is, ongeacht
ervaring, achtergrond, discipline (elektricien, programmeur, ingenieur) of
taalvaardigheid. Dit is een technisch project: de code en de metingen zijn de
maatstaf, niet de persoon die ze aanbrengt.

## Verwacht gedrag

- Kritiek op code, op een meting of op een aanname — met argumenten.
- Vragen stellen zonder je te verontschuldigen; niemand kent elk register.
- Fouten toegeven. Een verkeerde registermap die wordt rechtgezet, is winst.
- Respect voor andermans tijd: zoek eerst, vraag dan.

## Onaanvaardbaar

- Beledigingen, persoonlijke aanvallen, intimidatie, discriminatie.
- Publiceren van andermans privégegevens zonder toestemming.
- Bewust onveilige schrijfacties naar een installatie aanraden of een gevaar
  verbergen.
- Klantgegevens, IP-adressen of configuraties uit andermans omgeving delen.

## Handhaving

Meld een schending bij de maintainer. Klachten worden vertrouwelijk behandeld.
De maintainer kan een bijdrage weigeren, een gesprek sluiten of iemand
tijdelijk weren. Bij een ernstige schending volgt een permanente ban.

## Herkomst

Deze code is geïnspireerd op de [Contributor Covenant](https://www.contributor-covenant.org/),
versie 2.1, en toegespitst op een project waar fysieke installaties van afhangen.
